# Mango Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Claude Code mod that draws Mango, a fluffy black ASCII cat, in the band above the prompt and lets her react to the session.

**Architecture:** One plugin folder, `mango`. `hooks/cat.ts` holds the pure parts (frames, remarks, the test-command regex, the mood resolver). `hooks/register.tsx` holds the hooks: a clock that ticks an atom, a Bash observer, a turn observer, the `/mango` command and the `AbovePrompt` render. `types/index.d.ts` is the `$.state` contract. Persistent counters live in `$.store`.

**Tech Stack:** Claude Code function hooks (engine 2.1.287+, types from build 2.1.293), TypeScript/TSX compiled by the engine, `claude plugin validate`, `claude plugin test` with `claude-code/testing`. No npm dependencies.

**Spec:** `docs/superpowers/specs/2026-10-09-mango-design.md`

## Global Constraints

- Plugin name `mango`, command `/mango`, repo `mango-buddy`. The install line is `/plugin install mango --marketplace malinfossum/mango-buddy`.
- No `$.model.*`, `$.http`, `$.process`, no `telemetry.*` hooks. Nothing leaves the machine.
- The band renders constant strings only: never tool input, output, command text, paths or prompt text.
- The band holds no Buttons or Inputs.
- Pure ASCII art, plain English copy. No em dashes anywhere.
- One atom write per tick at most; still mode writes only on a mood change.
- Every hook has a `.catch` that calls `next(e)`; Mango never blocks a tool, prompt or turn.
- Store reads are coerced: numbers `Number(x) || 0`, flags `x === true`.
- Counters are read-modify-write at the moment of change.
- Commit after every task. Commits are plain, first person, no AI attribution.

## Review Focus

Inputs the spec implies but no test exercised until this plan added one. Each line's test lives in the task named.

1. A Bash command with leading whitespace or a `cd x && npm test` chain should still count as a test run (Task 2, `isTestCommand` cases).
2. A `tool.call` for Bash that is denied beneath Mango (`{ deny }`) has no `isError`; Mango must treat it as neither error nor success (Task 4).
3. `turn.complete` with `isAborted: true` still marks activity and still reads usage; no yawn for an aborted long turn (Task 5).
4. A `bodyColumns` narrower than the art (under 12) draws the art alone with an empty speech line, never a negative slice (Task 7).
5. `/mango` with trailing spaces or mixed case (`/mango  PET `) resolves to `pet` (Task 6).

import type { Register } from 'claude-code'
import type { Mood } from '../types'

const P = 'mango' as const
export const tick = atom({ plugin: P, key: 'tick' } as const, 0)
export const mood = atom({ plugin: P, key: 'mood' } as const, 'awake' as Mood)
export const moodUntil = atom({ plugin: P, key: 'moodUntil' } as const, 0)
export const lastActivityTick = atom({ plugin: P, key: 'lastActivityTick' } as const, 0)
export const contextPercent = atom({ plugin: P, key: 'contextPercent' } as const, 0)
export const remark = atom({ plugin: P, key: 'remark' } as const, null as string | null)
export const isSessionCounted = atom({ plugin: P, key: 'isSessionCounted' } as const, false)
export const wasOverBudget = atom({ plugin: P, key: 'wasOverBudget' } as const, false)
export const isOff = atom({ plugin: P, key: 'isOff' } as const, false)
export const isMuted = atom({ plugin: P, key: 'isMuted' } as const, false)
export const isStill = atom({ plugin: P, key: 'isStill' } as const, false)

export const register: Register = on => {
  on('ui.render', { component: 'AbovePrompt' }, async ($, e, next) => {
    if (e.props.hasSurvey || (await read($, isOff))) return next(e)
    const { Box, Text } = $.ui.resolve(e)
    const percent = await read($, contextPercent)
    return (
      <Box flexDirection="column">
        <Text key="row1">{' /\\_/\\'}</Text>
        <Box>
          <Text key="row2">{'( o.o )'}</Text>
          <Text>{'   '}</Text>
          <Text key="line" dimColor>{`context ${percent} %`}</Text>
        </Box>
      </Box>
    )
  }).catch(($, e, next) => next(e))
}

```ts
import type { Mood } from '../types'

export type Pose = Mood | 'working'

export const TICK_MS = 750
export const SLEEP_AFTER_TICKS = 160
export const RUFFLED_TICKS = 8
export const PROUD_TICKS = 12
export const BUDGET_PERCENT = 20
export const ART_WIDTH = 10
export const GAP = 2

const EARS = ' /\\_/\\'

const pad = (s: string): string => (s + '          ').slice(0, ART_WIDTH)

export const frameFor = (pose: Pose, tick: number): [string, string] => {
  switch (pose) {
    case 'awake': {
      const eyes = tick % 8 === 0 ? '( -.- )' : '( o.o )'
      const tail = tick % 2 === 1 ? ' ~' : '  '
      return [pad(EARS), pad(eyes + tail)]
    }
    case 'sleeping':
      return [pad(EARS), pad('( -.- )' + (tick % 2 === 0 ? ' z' : 'zz'))]
    case 'ruffled':
      return [pad(' \\/_\\/'), pad('( >.< ) !')]
    case 'proud':
      return [pad(EARS), pad('( ^.^ ) *')]
    case 'worried':
      return [pad(EARS), pad('( O.O )')]
    case 'working':
      return [pad(EARS), pad(tick % 2 === 0 ? '( o.o )nn' : '( o.o ) nn')]
  }
}

export const faceFor = (pose: Pose, tick: number): string => {
  switch (pose) {
    case 'awake':
      return tick % 8 === 0 ? '(-.-)' : '(o.o)'
    case 'sleeping':
      return '(-.-)'
    case 'ruffled':
      return '(>.<)'
    case 'proud':
      return '(^.^)'
    case 'worried':
      return '(O.O)'
    case 'working':
      return '(o.o)'
  }
}

const REMARKS: Record<Mood | 'purr' | 'yawn', readonly string[]> = {
  awake: ['Mango is watching.', 'Mango sits on the keyboard, just a little.', 'Mango blinks slowly at you.', 'Mango approves of this tab.', 'Mango is here.'],
  sleeping: ['Mango is asleep. Type gently.', 'Mango dreams of warm laptops.', 'Mango curls up on the prompt.', 'Mango is off duty.'],
  ruffled: ['Mango did not like that one.', 'Mango flattens her ears.', 'Mango knocks the error off the table.', 'Mango stares at the stack trace.', 'Mango will allow one retry.'],
  proud: ['Mango purrs at the green run.', 'Mango knew you would get it.', 'Mango stretches. Tests pass.', 'Mango sits taller now.', 'Mango is pleased.'],
  worried: ['Mango eyes the context meter.', 'Mango thinks this is a lot of context.', 'Mango suggests saving and clearing soon.', 'Mango paces. The window is filling.'],
  purr: ['Mango purrs.', 'Mango leans into your hand.', 'Mango closes her eyes and rumbles.', 'Mango headbutts the cursor.'],
  yawn: ['Mango yawns. That was a long one.', 'Mango checks the clock. Still here.', 'Mango stretches after the long turn.', 'Mango wonders if you need a break too.'],
}

export const remarkFor = (mood: Mood | 'purr' | 'yawn', tick: number): string => {
  const lines = REMARKS[mood]
  return lines[Math.abs(tick) % lines.length]
}

const TEST_COMMAND = /\b(npm|pnpm|yarn|bun)\s+(run\s+)?test\b|\b(vitest|jest)\b|\bdotnet\s+test\b/

export const isTestCommand = (command: string): boolean => TEST_COMMAND.test(command.trim())

export const resolveMood = (s: {
  mood: Mood
  moodUntil: number
  tick: number
  lastActivityTick: number
  contextPercent: number
}): Mood => {
  const isTimed = s.mood === 'ruffled' || s.mood === 'proud'
  if (isTimed && s.tick < s.moodUntil) return s.mood
  if (s.contextPercent >= BUDGET_PERCENT) return 'worried'
  if (s.tick - s.lastActivityTick >= SLEEP_AFTER_TICKS) return 'sleeping'
  return 'awake'
}
```

- [ ] **Step 3: Implement the clock and the live render**

Replace the body of `register` in `hooks/register.tsx` with:
```tsx
import { frameFor, resolveMood, TICK_MS } from './cat'

const flag = (x: unknown): boolean => x === true

const snapshot = async ($: EngineType, t: number) => ({
  mood: await read($, mood),
  moodUntil: await read($, moodUntil),
  tick: t,
  lastActivityTick: await read($, lastActivityTick),
  contextPercent: await read($, contextPercent),
})

export const markActivity = async ($: EngineType) => {
  const t = await read($, tick)
  await update($, lastActivityTick, () => t)
}

export const register: Register = on => {
  on('session.start', async ($, e, next) => {
    await update($, isOff, () => flag(await $.store.get('isOff')))
    await update($, isMuted, () => flag(await $.store.get('isMuted')))
    await update($, isStill, () => flag(await $.store.get('isStill')))

    $.clock.every(TICK_MS, async () => {
      const t = (await read($, tick)) + 1
      if (!(await read($, isStill))) {
        await update($, tick, () => t)
        return
      }
      const s = await snapshot($, t)
      if (resolveMood(s) !== resolveMood({ ...s, tick: t - 1 })) await update($, tick, () => t)
    })
    return next(e)
  }).catch(($, e, next) => next(e))

  on('tool.call', { tool: 'Bash' }, async ($, e, next) => {
    await markActivity($)
    return next(e)
  }).catch(($, e, next) => next(e))

  on('ui.render', { component: 'AbovePrompt' }, async ($, e, next) => {
    if (e.props.hasSurvey || (await read($, isOff))) return next(e)
    const { Box, Text } = $.ui.resolve(e)
    const t = await read($, tick)
    const s = await snapshot($, t)
    const pose = e.props.isWorking ? 'working' : resolveMood(s)
    const [row1, row2] = frameFor(pose, t)
    return (
      <Box flexDirection="column">
        <Text key="row1">{row1}</Text>
        <Box>
          <Text key="row2">{row2}</Text>
          <Text>{'  '}</Text>
          <Text key="line" dimColor>{`context ${s.contextPercent} %`}</Text>
        </Box>
      </Box>
    )
  }).catch(($, e, next) => next(e))
}
```

Note: if `$.clock.every` throws, the `.catch` calls `next(e)` and the session goes on with a static Mango. That is the intended degrade.

import { BUDGET_PERCENT } from './cat'

on('turn.complete', async ($, e, next) => {
  await markActivity($)
  try {
    const { context } = await $.session.usage()
    const percent =
      context.percent ??
      (context.window > 0 && context.tokens !== undefined ? (context.tokens / context.window) * 100 : undefined)
    if (percent !== undefined) {
      const rounded = Math.round(percent)
      await update($, contextPercent, () => rounded)
      const over = rounded >= BUDGET_PERCENT
      const was = await read($, wasOverBudget)

        await update($, remark, () => remarkFor('worried', t))
      }
      if (!over && was) await update($, remark, () => null)
      await update($, wasOverBudget, () => over)
    }
  } catch {
    // usage unavailable: keep the previous figure
  }
  if (!e.isAborted && e.durationMs > 120000) {
    const t = await read($, tick)
    await update($, remark, () => remarkFor('yawn', t))
  }
  return next(e)
}).catch(($, e, next) => next(e))

  await update($, remark, () => null)
  return next(e)
